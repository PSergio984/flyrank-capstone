# Features Research

## Table Stakes (must have)

- Express.js server listening on a configurable port
- GET / endpoint returning welcome JSON
- GET /about endpoint returning developer/assignment info JSON
- Package.json with proper scripts (start, dev)
- .gitignore for Node.js

## Differentiators (nice to have for this assignment)

- Auto-generated API docs via Swagger/OpenAPI
- Error handling middleware
- Request logging (morgan)
- CORS headers

## Anti-features (deliberately not building)

- Database — assignment asks for simple request-response demo
- Authentication — out of scope for BE-01
- HTML views — API-only
